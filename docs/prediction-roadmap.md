# QuantChive 前瞻预测能力 · 路线图

> 定位:把用户的"三步走"(①资金信号回测统计 → ②ML 预测 → ③基本面/消息面)按**数据成熟度**排成务实路线。
> 本文档基于 4 维度调研 + 本地实测探针,诚实标注每步的前置数据条件。**不画饼:不够做的直说不够。**

---

## 0. 头号约束的翻转 —— 资金流历史(实测)

### 曾以为的约束
全市场四档资金流(gross+net)当前只有 **19 个交易日**(2026-06-08 ~ 07-03)。
→ 有效独立样本 ≈ 19(远低于统计下限 30),任何"胜率 XX%"都是噪声,不能对外说。

### 实测翻转(2026-07-06 探针)
根因不是接口限制,是**从没用逐股历史端点回填,只靠每日快照攒**。实测新浪逐股接口 `MoneyFlow`:

| `num` 参数 | 返回行 | 覆盖深度 |
|---|---|---|
| 800(现有默认) | 800 | 2023-03 ~ 今(3年) |
| 2000 | 2000 | 2018-03 ~ 今(8年) |
| **5000** | **3962(到顶)** | **2010-03 ~ 今(16年!)** |

**且 16 年前的老数据带完整四档 gross + net + 价格**(实测 2010-03-01 茅台 r0_net/trade 均有值)。

### 结论(关键)
**新浪逐股回填 `num=5000` 免费可补全市场 ~16 年四档资金流历史。** 不必开 Tushare。
- **代价**:5000+ 股逐个请求,需限速 + 重试(复用现有 collect_lock + 节流 + 读回校验),约数小时全市场跑完,一次性。
- **物理天花板不变**:仍是盘后日频;盘中逐分钟 gross 仍无源(与 MEMORY「探新浪实时档位」是同一个洞,不影响日频回测/ML)。
- Tushare(200元/年,15年)作为**备选/交叉校验源**,非必需。

## 2. 推荐落地顺序

### 阶段 A — 补深资金流(解锁 ①③ 的地基,免费)
- 改 `backfill_flow_history`:`max_rows=800 → 5000`(单参数),逐股全市场回填
- 复用现有:`collect_lock`(并发锁)、页间节流、读回校验、`coverage_range` 增量补缺
- 产出:全市场 ~16 年四档 gross+net 日线入库(观测三表不变,只是深度从 19 天 → 3900+ 天)
- 验证:抽样几只股确认历史深度 + 恒等式自检(gross≥|net|)

### 阶段 B — 价格标签管道 + 事件研究框架(免费,与 A 并行)
- baostock 复权日线(实测 20-35 年):算"信号后 T 日涨跌"标签
- **必改:qfq → hfq**(后复权)。前复权每逢分红送股整体重算历史价 → 存库标签漂移、破坏回测可复现。现 `ingest_service.py` backfill 默认 qfq,改/补 hfq
- 多日累计收益**链式乘 hfq close**,勿累加 pctChg
- 事件研究骨架:信号定义 → T+1..T+5 前向收益分布 → Wilson 置信区间 → 对照无条件基准(A股日涨~50%)

### 阶段 C — 步骤① 信号回测(A+B 完成后)
- 信号库:背离(吸筹/派发,已有检测逻辑)、连续净流入/出 N 日、超大单异动、主力散户背离
- 回测:每信号触发后前向收益分布 + Wilson CI + 非参检验(符号/Corrado秩)+ bootstrap
- **防前视铁律**:universe 按 `membership as-of`(已有)防幸存者偏差;标签与信号时间戳严格错位;剔除退市股
- 新工具 `signal_backtest(股/全市场, 信号类型)` → agent 可答"该信号历史 N 次,5日胜率 X%(CI a%~b%)——历史统计,非预测"
- 产出话术标注**"历史假设"**,不承诺胜率

### 阶段 D — 基本面接入(独立,可提前/并行)
- 优先东财三大报表+业绩(`stock_zcfz_em`/`lrb_em`/`yjbb_em`…):免费拉全市场十几年,无限流
- **必做 PIT**:按**公告日**(`yjbb_em` 最新公告日期 / 巨潮公告日)对齐,优先首次披露值 → 防未来函数
- akshare 逆向封装,**锁版本 + 薄适配收口**(仿 `RawObservation`),不裸调
- 研报评级(`stock_research_report_em`)+ 巨潮公告事件流 → 事件研究
- 消息面:免费源只做**实时信号**,历史回测用可回溯事件流(研报/公告/新闻联播)替代原始新闻

### 阶段 E — 步骤③ ML 预测(C 稳定 + 资金流攒足后)
- 前置:①的 hfq 标签 + 16年资金流(阶段A已给)
- 模型:正则 Logistic / 浅层 LightGBM(深≤3强正则);二分类次日涨跌(不做点预测回归)
- 特征个位数、全资金流构造 + 标准化(各档净额、大小单背离比、净流入1/3/5日动量、z-score用**trailing窗**、量价背离)
- **防泄漏铁律**:z-score 只用 trailing(用全样本 mean/std 是最隐蔽泄漏);walk-forward 或 purged k-fold + embargo(~1月);**绝不 random shuffle CV**;对比朴素基准

## 3. 诚实边界(必须向用户设定预期)

- **次日个股方向准确率天花板 51-55%**(严谨 OOS 研究)。宣称 70%+/80%+ 的几乎都源于前视泄漏/过拟合/换了更易目标。
- OOS R² 通常 0.29%-0.95%(金融里已算好)。
- 资金流失衡是**强同期、强超短(秒-分钟)**因子,**弱次日、弱个股**,信号 1 日后快速衰减。
- **可预测 ≠ 可盈利**(散户委托失衡正向预测但被价差吃掉)。
- 产品定位:资金流信号 = "**微弱但真实的边际概率倾斜**",输出**概率/置信区间/历史条件胜率**,而非二元"涨/跌"断言。定位为"次日涨跌预测器"= 过度承诺。

## 3.5 阶段A/B 已落地(2026-07 实现)

- **阶段A ✅**:sina 逐股 num=5000 回填近5年全市场四档资金流(5960股,592万行)。
- **阶段B ✅**:信号回测框架落地。
  - `service/signal_lib.py`:4种逐日点信号(吸筹/派发背离、连续净流入、超大单异动z-score),纯函数、trailing窗防前视。
  - `service/backtest_core.py`:前向收益链式乘、Wilson 95%CI 闭式(无scipy)、对照基准、n<30标注不可靠。
  - `service/backtest_service.py`:**标签源混合** —— sina change_pct_bp 链式乘价指数(默认,0成本即时全市场、复权无关可复现)/ baostock_hfq(可选升级,总回报最严谨,需回填)。股息微偏在信号vs基准对比中抵消(实测两法 edge 一致)。
  - API `/api/subjects/{id}/signal_backtest` + MCP `signal_backtest`(第16工具) + agent 允许信号历史胜率(仍禁编概率)。
  - **实测**:baostock hfq 全市场回填要~15h(5-7秒/股,非预估1.5h)→ 故 sina 链式做默认。平安银行"连续净流入"信号 T+1 胜率52% vs基准45%(+7.5pp edge)。
- 阶段C(信号回测)其实随B一起完成。**剩阶段D(基本面)/E(ML)** 是后续独立工程。

## 5. 立即可做 vs 需等

- **立即(免费,本轮可启动)**:阶段 A(补深资金流)+ B(价格标签+框架)+ D(基本面接入)
- **A+B 完成后**:阶段 C(信号回测,真数据)
- **C 稳定 + 数据攒足**:阶段 E(ML)
- **不做**:消息面历史回测(免费源做不成)、盘中逐分钟 gross(无源)——诚实排除
