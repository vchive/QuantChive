# 资金档位博弈 · 术语与看图指南

> 这份文档是**给你（使用者）看的**，帮你读懂 QuantChive 的资金档位博弈可视化。
> 产品本身保持专业（对标东财/同花顺），不放新手气泡——术语讲解都在这里。

---

## 一、四个资金档位（按单笔成交金额分档）

A股把每笔成交按**金额大小**分成四档（东财/新浪口径）：

| 档位 | 含义 | 通常代表 |
|---|---|---|
| **超大单** | 单笔成交金额最大的一档 | 机构、主力大资金 |
| **大单** | 次大 | 大户、游资 |
| **中单** | 中等 | 中户 |
| **小单** | 最小 | 散户 |

**主力 = 超大单 + 大单**；**散户 = 中单 + 小单**。这是"主力 vs 散户"博弈的基础。

---

## 二、三个核心概念：净额 / 流入 / 流出

某档位在某一天：

- **流入（成交额买方）**：这一档主动买入的钱
- **流出（成交额卖方）**：这一档主动卖出的钱
- **净额 = 流入 − 流出**：正=净买入（钱在进），负=净卖出（钱在出）
- **成交额（gross）= 流入 + 流出**：这一档总共成交了多少钱

QuantChive 后端由 `net`（净额）和 `gross`（成交额）反推：
```
流入 = (成交额 + 净额) / 2
流出 = (成交额 − 净额) / 2
```
所以看到"超大单流入 1.09亿 / 流出 9743万"，就是超大单里买入 1.09 亿、卖出 9743 万，净买入约 1119 万。

> **为什么盘中只有净额、没有流入流出？** 盘中实时数据源（东财）只发净额，不发成交额（gross），无法反推流入流出——这是数据源的物理限制，不是缺陷。所以"逐分钟回放"只画净额博弈。历史日线有新浪的成交额，才能看流入流出。

## 三、四个视图怎么看

### 1. 博弈主图（默认）
三格联动：
- **上格 价格**：红线是股价
- **中格 四档柱**：每天四档净额，**向上红=净流入、向下绿=净流出**；颜色深浅表档位（超大最深）
- **下格 累计线**：累计主力（红）vs 累计散户（绿），看谁在持续进场

**看什么**：主力柱子持续向上（红）= 主力在买；配合下格累计主力线一路上升 = 主力在建仓。

### 2. 四档热力
一屏看全四档的时间演化：4 行（超大/大/中/小）× 时间，**格子颜色**=当天该档净额（红入绿出、越深越强）。上方对齐价格线。

**看什么**：哪一档在哪段时间最活跃、方向如何，一眼扫完。

### 3. 逐分钟回放（盘中）
盘中四档净额柱**逐分钟"长出来"** + 价格竖线随帧移动。点播放看当天资金怎么一分钟一分钟拉锯。

**看什么**：当天主力和散户的实时博弈过程（只净额，见上文说明）。

### 4. 对抗象限
- **上**：累计主力 vs 累计散户镜像面积，张口越大博弈越激烈
- **下 象限散点**：每天一个点，x=当天涨跌幅、y=主力净额。**高亮红点=逆势吸筹**（价跌但主力在买）

**看什么**：逆势吸筹的点（左上象限，价跌主力买）——这是"主力低位建仓"的经典信号。

---

## 四、关键信号：背离

主图会自动标记**背离段**（淡色高亮）：

- **吸筹（accumulation）**：一段时间里**价格在跌，但主力累计净额在升**。主力趁跌吸货，价未涨=还在建仓。
- **派发（distribution）**：**价格在涨，但主力累计净额在降**。主力趁涨出货。

背离是资金流最有价值的信号——**价格骗人，钱不骗人**。价跌时看主力是否偷偷在买，比看 K 线更早发现主力意图。

---

## 五、数据说明（诚实分级）

- **历史日线**：新浪源，约 8 年，有成交额→能看流入流出、背离、建仓。数据足。
- **盘中分钟**：东财源，只当天、只净额→看当日实时博弈回放。数据短、无流入流出。
- **数据来源角标**：多源交叉校验，"✓校验通过"或"⚠️口径分歧"——分歧时人工判断信哪个源，系统绝不自动改数据。
- **断点不连线、超保留窗如实提示**——绝不插值造假。各源档位阈值定义不同，数值有差是正常口径差异。
